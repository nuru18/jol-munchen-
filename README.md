# Munchen pub — собранный сайт

Готовая сборка концепт-редизайна сайта немецкого паба **Munchen pub**
(Бишкек, БЦ «МОТО», улица Токтогула, 87а, 5 этаж). Здесь только результат
сборки — исходники в отдельном проекте.

> Концепт-редизайн, неофициально. Данные, меню и фото — из публичной карточки 2ГИС.

Адрес: https://nuru18.github.io/jol-munchen-/

## Что обновилось

**Три языка:** русский, кыргызский, английский. Названия блюд и описания
сортов оставлены так, как их печатает сам паб.

**«Именинникам −10% + сюрприз»** — акция из карточки. Подставляете день
и месяц: сайт считает, сколько ждать и что снимет скидка с выбранного сета.
29 февраля в невисокосный год отмечаем 1 марта.

**Меню выросло с 28 до 44 позиций** — добраны сеты, стейки и закуски с их
собственных промо-карточек: мясной метр 4459с/2кг, дрезденское ассорти,
рыбный сет, Т-Бон, форель с овощами гриль.

**Фотографий 40 вместо 20.** У них почти весь альбом — вечеринки с портретами
гостей, поэтому брали только студийную съёмку блюд и общие планы зала.

**Убраны выдуманные отзывы.** Три сочинённые цитаты «от гостя» с пятью
звёздами заменены реальными цифрами: 4.8, 1478 отзывов, две награды 2ГИС
и ссылка на источник.
