# Munchen pub — собранный сайт

Готовая сборка концепт-редизайна сайта немецкого паба **Munchen pub**
(Бишкек, ул. Токтогула, 87а, БЦ «МОТО», 5 этаж). Здесь лежит только
результат сборки — исходники в отдельном проекте.

> Концепт-редизайн, неофициально. Данные и фото — из публичной карточки 2ГИС.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**,
папка **/ (root)** → Save.

Дальше важно: Pages запускает сборку по пушу. Если после включения ничего
не публикуется — сделайте любой коммит в `main`, и сайт соберётся за минуту.

Адрес будет:
https://nuru18.github.io/jol-munchen-/

Сайт раздаётся из подпапки, поэтому все пути относительные, а маршруты —
на `HashRouter`. Файл `.nojekyll` отключает обработку Jekyll.

## Что внутри

| Раздел | Содержимое |
|---|---|
| Пиво | Пять сортов своей варки с плотностью и крепостью, фильтр по цвету |
| Кухня | Пивные сеты, супы, стейки, колбаски, гарниры |
| Паб | До 300 мест, панорама, живая музыка, 3D-экскурсия |
| Репутация | 4.8 при 1478 отзывах, две награды 2ГИС |
| Бронь | Три зала с проверкой числа гостей |
| Меню | Полная карта с поиском по адресу `#/menu` |

Меню целиком снято с 37 фотографий меню, выложенных самим пабом.
